# Binder-Example
Deomstrating how a reader of the book can access worked code examples for the problem set using a binder environment.

Click the Badge below to load the Binder app. This will take a minute or so to load into a JuPyterLab project. You can then navigate to Chapter 1, problem 1 to see how the content would look. 

[![Binder](https://mybinder.org/badge_logo.svg)](https://mybinder.org/v2/gh/Fraser-Crawford/Binder-Example/HEAD)

Binder is useful as it will handle the download and managing of the user's programming environment, ensuring the code will work first time on any machine, regardless on their current python installation. 
I make use of a common code folder to get rid of a lot of the bloat that may make the program harder to read. This also allows for reuse of functions in other notebooks in the project. Another option is to use hidden cells, however the user would then not be able to see the origin of where most of the code came from.
